# Bylaw Compliance Checker

Checks a building model from a Revit add-in or an IFC upload against NBC 2016 and city development control rules. A Nemotron agent turns regulation clauses into executable checks, and Tavily finds and refreshes city rule sources. Every flag cites its clause, and results are sent back into Revit.

Built for the Nebius × NVIDIA Global AI Hackathon (2026), Best Apps and Agents track.
